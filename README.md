Functionalities & Solutions Implemented:


Group Management: Admin can create groups, share invite links and remove participants from a group.
Message Deletion: Users can delete messages within 1 minute, appearing as "This message was deleted." in both personal and group chats.
Read & Delivery Tracking: Real-time insights on who read/delivered messages with timestamps.
Personal Chat from Group: Click on a group member to start a direct personal chat.
Online/Offline Status: Real-time visibility of a user's online status during personal chats.
Reply System: Users can reply to both group and personal messages.
Unread Messages Indicator: Displays count of unread messages in group & personal chats.
Last Message Preview: Chat home page shows last message preview for each chat.
Notification System: Alerts users about new messages while scrolling in group chat.
Efficient Navigation: Clicking the unread message alert scrolls to the first unread message.
Optimized WebSockets: High-performance real-time updates for a seamless chat experience.
Redis-based Presence Tracking: Used Redis CLI to track online users and opened chat pages to avoid redundant notifications.
